# Wordwise

A small dictionary app for looking up definitions, pronunciations, and example sentences. It uses the [Free Dictionary API](https://dictionaryapi.dev/) and plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser, or serve this folder locally:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`. No build step or package install is needed.
